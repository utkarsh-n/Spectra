# Spectra (native) — build spec, part 2: features per tab

Every tab: `TopBar` (Dials button top-left · tab title · glass capsule with ⓘ Field notes and ⚙ Settings), `SpectrumStrip` under it, content, floating `Transport` (Play/Pause, Step, ⋯, time-mapping chip with slow-motion factor, ALIASED chip when relevant). Tab bar: Spectrum (`waveform`), Radio (`antenna.radiowaves.left.and.right`), Live (`dot.radiowaves.left.and.right`), Spin (`gyroscope`), Patch (`point.3.connected.trianglepath.dotted`) — verify every SF Symbol name exists in `/System/Library/CoreServices/CoreGlyphs.bundle/Contents/Resources/name_availability.plist` (Gyre gotcha) and substitute if not.

## 1. Spectrum tab (port of spectra-lab; parity-tested core)
Band segmented control (γ X UV Vis IR µW Radio — jumps to representative λ), instrument chips (01 Wave scope, 02 Spectrum tuner, 03 Matter bench, 04 Decompose, 05 Spectroscopy lab), instrument panel with Align + full-screen, status line, readouts grid, aux area — exactly the web prototype's behaviour (`spectra-lab/src/instruments/*.js`, `src/ui/*.js`), restyled natively:
- **Wave scope**: Metal holo scene — E (blue) and B (red) traces with ribbons and stems, beam axis in the wave's display colour, S arrow, per-source faint traces, medium block with Fresnel/absorption (FieldView port), drag/pinch/double-tap camera; toggles E/B/S.
- **Spectrum tuner**: Canvas log ruler (extend to `LOG_MIN = -13 … LOG_MAX = 8`, i.e. up to 100,000 km, with the web range as the default visible window and a pinch to zoom the decades; mark Earth-field NMR 140.8 km, mains 5,000/6,000 km, Schumann 7.83 Hz ≈ 38,000 km), λ/f/E axes, size comparisons, ionizing and pair-production lines, cursors for A/B/C plus *every* app marker (dimmer), drag with band-edge detents (haptic + sound tick), thermal Planck curve, pulse bandwidth.
- **Matter bench**: the seven specimens with TABLE/MODEL badges, side-by-side / in-series, focused-specimen animated stage (Canvas), resonance haptic thumps, oscillator λ₀ slider.
- **Decompose**: Polarization (head-on view, Ex/Ey strips, polarizer slider, Malus/circular readouts; show "—" for circular orientation, port-plan bug note), Probe charge (exact trajectory, E+v×B / E only / B only, a₀ slider, drift-frame figure-eight inset), Fourier (time trace + stems + prism inset).
- **Spectroscopy lab**: hydrogen (emission/absorption with spectroscope strip), CO₂ IR/Raman, liquid water IR (TABLE), chlorophyll a/b, ethanol ¹H NMR at 400/60 MHz **plus a third mode "Earth field (live |B|)"** that uses the live magnetometer magnitude for B₀ (~2 kHz) and links to the Spin tab. Sweep retunes the active source.
- **Field controls sheet**: field trips (14 presets), sources A/B/C + Link + on/off, kind (plane/pulse/thermal), GlassKnobs λ (log), T, E₀ (log), θ, δ, φ, N; medium segmented; κ display speed; display toggles; pinned Reset dials / Reset alignment.
- Physics comes from `Core/` (ported, parity-tested against `spectra-lab/tests/parity/vectors.json`, 11,746 cases).

## 2. Radio tab (RF Lab)
Page picker `.pickerStyle(.tabs)` (iOS 27; Gyre uses it): **Antenna · Systems · Fourier · Link**. One shared `RadioModel`: selected system (carrier f, bandwidth, modulation, multiplexing), antenna (style + parameters), channel, link. The carrier appears as a marker on the strip; "Tune Spectrum here" sends it.
- **Antenna**: style chips — Short dipole, Dipole (L/λ knob 0.1–3), Monopole, Small loop (also NFC/Qi coil), Patch (εr knob), Yagi (N elements 3–20), Helix (N turns, C/λ), Horn, Dish (D/λ), Phased array (N, d/λ, steer θ₀ knob → grating lobes appear past the limit), PIFA (phone). Metal holo scene: 3D radiation lobe (surface as a lit wire-mesh of the |E| pattern, colour = band colour of the carrier), antenna geometry glyph, a "your phone" frame. **Follow phone** toggle: pattern rotates with the live attitude quaternion; **Beam lock**: the phased array re-steers to keep a world direction (Gyre lesson). Polar cuts (E-plane/H-plane, Canvas). Readouts: directivity (dBi), HPBW, Rr / Zin, VSWR and mismatch loss to 50 Ω, efficiency, bandwidth, effective aperture Ae = Gλ²/4π, far-field boundary 2D²/λ, polarization; PLF vs a reference (cos²). All formulas from `rf-physics.md` verified reference.
- **Systems**: a scrolling timeline of generation cards: 1G AMPS → 2G GSM/IS-95 → 2.5G EDGE → 3G UMTS/HSPA → 4G LTE → 5G NR FR1/FR2 → 6G (SPECULATIVE badge); Wi-Fi 802.11b/a/g/n/ac/ax/6E/be; Bluetooth Classic/BLE; GPS L1/L5; NFC; UWB ch5/ch9; AM, FM, DAB/TV; Qi. Each card: band(s), channel width, modulation/multiplexing, max order QAM, peak rate, year, "in your iPhone?" (from `rf-physics.md` §F). Select → sets the RadioModel system and jumps to Fourier. Filter chips: Cellular / Wi-Fi / Personal / Navigation / Broadcast.
- **Fourier**: for the selected system a real baseband simulation at a manageable rate: generate symbols (BPSK/QPSK/8PSK/16–4096QAM/GFSK/GMSK/AM/FM/OFDM/DSSS chips), pulse shaping, optional OFDM (subcarrier count/spacing scaled, cyclic prefix), channel (AWGN SNR knob, multipath delay-spread knob, Doppler knob, Rician K), receiver (equalizer for OFDM, EVM, BER estimate vs theory). Views: I/Q time trace, constellation (received vs ideal), spectrum (FFT, Hann, dB, channel mask, adjacent channels), waterfall. Message source picker: random bits / **live mic voice** (AM/FM: demodulate and play back through HumSynth, push-to-talk) / text.
- **Link**: Friis/log-distance budget: Tx power, Tx/Rx gains (from Antenna), distance (log knob 1 cm–40,000 km, detents: 1 m, room, house, km, cell edge, GPS orbit 20,200 km), environment (free space / indoor office / urban macro per 38.901), walls (materials: glass, IRR glass, concrete, wood; counts), rain and gas at mmWave, noise figure, bandwidth → received power, noise floor (−174 dBm/Hz + 10 log B + NF), SNR, Shannon capacity vs the system's peak; a bar-chart budget; **Live check**: pick a nearby BLE device → compare its live RSSI with the model and solve for distance (path-loss exponent knob).

## 3. Live tab (simulation → live)
A vertical stack of live cards (each: title, provenance badge, permission state, measured rate, primary readout, sparkline/plot, "Show on spectrum" and "Add to Patch"). Cards start their source when visible. Order:
1. **Your iPhone's antennas**: schematic of the iPhone 15 Pro Max outline with side-rail antenna segments (general, labelled MODEL), and a list of its radios with bands (cellular LTE/5G FR1 + FR2 on US models, Wi-Fi 6E, BT 5.3, UWB, NFC, GPS L1+L5, MagSafe/Qi2) — each row tappable to show its band on the strip.
2. **Bluetooth**: scanning list (name if advertised, RSSI dBm sparkline, Tx power, estimated distance via log-distance with exponent knob, channel 37/38/39 note), a radar view, the **turntable experiment** (rotate the phone; RSSI binned by yaw → measured pattern vs a dipole model).
3. **Cellular & Wi-Fi**: current RAT per SIM (LTE / NR NSA / NR), radio type (sub-6 / mmWave) when exposed, Wi-Fi standard and `linkQuality`, interface, RTT; mapped to the Systems cards ("You are on 5G NR NSA → open card").
4. **Satellites (GNSS)**: fix, ±accuracy, ellipsoidal altitude, L1 1575.42 MHz / L5 1176.45 MHz, distance to the constellation (20,200 km) and light time (67 ms), received power ≈ −130 dBm vs noise floor.
5. **Magnetometer (ELF)**: |B| µT, vector arrow, dip angle → magnetic latitude, measured sample rate, FFT 0…fs/2 (timestamped samples, Hann), aliasing explainer (60 Hz → ~40 Hz at ~100 Hz), "Hear Earth-field NMR" → Spin.
6. **Microphone (ANALOGY)**: spectrum + waterfall (48 kHz, 4096-point FFT), loudest frequency, "this is sound, not light" note; source for the Patch and Radio voice.
7. **Light meter**: camera exposure → EV, approximate lux, CCT (K) → blackbody temperature marker on the Spectrum tuner; front/back toggle.
8. **Air**: barometer kPa, relative altitude, radio refractivity N, radio horizon for your height, GNSS zenith delay, O₂ absorption at 60 GHz.
9. **Charging**: battery state → "If MagSafe/Qi: ~110–205 kHz" INFERRED marker.
10. **UWB** (NEEDS PEER) and **NFC** (LOCKED) cards with honest explanation and the model view.
11. **Sensor census** (debug list in Settings → Sensors): measured rates of every source, capability flags (`sdk-sensors.md` §7).

## 3b. Scope (oscilloscope for every sensor, radio and simulation) — Live tab page "Scope"
The Live tab has a page picker (`.pickerStyle(.tabs)`): **Sensors** (the cards above) · **Scope**. Every Live card, Spin FID, Radio I/Q and Patch node has "Open in Scope". The same `ScopeView` is the Patch "Scope" sink.
- **Phosphor display**: Metal accumulation buffer with adjustable **persistence** (phosphor decay, Orbitals glow), graticule 10×8 div, up to **4 channels** (CH1–CH4 colours: phosphor, amber, ice `#8FD3FF`, rose; EM streams may use their band colour) + 1 **math** channel.
- **Channel source**: any `SignalStream` from the registry, grouped (Magnetometer, Motion, Bluetooth, Network, Audio, Light, Air, Location, Spin, Radio, Patch), with provenance badge, unit and measured rate.
- **Modes**: YT sweep · **Roll** (auto for timebases ≥ 0.5 s/div; seismograph style) · **XY** (any two channels: compass Lissajous from mag X/Y, accelerometer orbit) · **FFT** (Hann, dB, log-f, peak marker, aliasing note when the stream's Nyquist is near a known source like mains) · **Spectrogram** (waterfall).
- **Controls** (GlassKnobs with detents): timebase s/div (log, 10 µs…10 s; clamped by the stream's rate — audio reaches µs, motion ~10 ms, BLE ~100 ms+), per-channel units/div (log), offset, coupling DC/AC (1-pole high-pass, also "remove gravity"/"remove Earth field"), invert; trigger: Auto/Normal/Single, source, level, slope, holdoff; Run/Stop (freeze); cursors (Δt → 1/Δt, ΔY); measurements per channel: frequency (zero-crossing + FFT peak), period, Pk-Pk, RMS, mean, min, max; math: A+B, A−B, A·B, |vector| (e.g. √(x²+y²+z²)), d/dt, ∫dt, high-pass; export CSV (share sheet) of the visible window.
- **Presets** ("probes"):
  1. **Magnetic scope** — mag X/Y/Z + |B| (µT), AC-coupled option to reveal mains hum; FFT shows the 60→~40 Hz alias explainer.
  2. **Vibration** — accelerometer X/Y/Z (g, gravity removed) + gyroscope |ω|; put the phone on a washing machine/table/speaker; FFT of vibration, RMS in mg.
  3. **Seismograph** — accelerometer Z in Roll mode at 1 s/div, high-pass, auto-scale.
  4. **Bluetooth / EMF** — RSSI (dBm) of the 3 strongest BLE devices (event-driven, sample-and-hold drawing) + |B|; honest caption: the phone has no broadband RF power meter; BLE RSSI is per-device radio strength, the magnetometer sees DC–~50 Hz fields only.
  5. **Network** — Wi-Fi/cellular RTT (ms) and link quality steps.
  6. **Sound** — microphone at 48 kHz (ANALOGY), 1 ms/div, triggerable; FFT up to 24 kHz.
  7. **Compass XY** — mag X vs Y (rotate the phone to draw the calibration circle/ellipse).
  8. **Air** — barometer (Pa) with relative altitude; walk stairs.
  9. **Light flicker (experimental)** — camera row-mean of a rolling-shutter frame gives a high-rate light signal (row time ≈ frame time / rows, several kHz effective); reveals 100/120 Hz LED/lamp flicker from mains. Marked MODEL·LIVE with the method explained; validate on device (sensor census).
  10. **Spin FID** and **Radio I/Q** (simulated streams, MODEL).
- **Rates honesty**: each channel shows its measured sample rate; timebase knob stops at what the stream can show; a dashed "sample-and-hold" style for irregular streams; ALIASED chip when a known source frequency exceeds Nyquist.
- Additional sensor streams to publish for the scope (live owner): accelerometer x/y/z (user acceleration and raw), gyroscope x/y/z, attitude roll/pitch/yaw, gravity, magnetometer raw + calibrated x/y/z + |B|, barometer pressure + relative altitude, mic L (and level), BLE RSSI per device, Wi-Fi/cell RTT, link quality, GNSS horizontal accuracy, speed, altitude, heading (true/magnetic), camera EV/lux/CCT and flicker row-signal, battery level/state, thermal state (step stream), proximity (if `UIDevice.isProximityMonitoringEnabled` works). Check `CMBatchedSensorManager` (high-rate accelerometer) availability on iPhone in the SDK and census; use it if supported.

## 3c. Phase space: the spacetime Wigner distribution (Utkarsh's construction)
Reference: `Docs/research/wigner-spacetime.md` — use his convention (C) and definition of Φ(ν,k;x,t) exactly, credit him in the field notes, and follow the six implementation rules there (lag window, 2× oversampling / analytic signal, real signals → Wigner–Ville, global phase, exact vs smoothed views, dispersion shells).
- **Spectrum → Decompose gets a 4th tab "Phase space"** laid out like his poster: left, the spacetime view |ψ(x,t)|² (x vertical, t horizontal, phosphor heat map); right, the momentum–frequency view |ψ̃(k,ν)|² with the selected medium's dispersion curve overlaid (vacuum light line, Sellmeier glass, water, plasma ω² = ω_p² + c²k² with an ionosphere f_p knob, waveguide cut-off); centre, the Φ cube (axes space · time · frequency, k integrated or a selectable k slice) as a Metal volume (point/slab sprites, diverging map: positive warm orange, negative cool blue, as in the poster) with drag-rotate. Slices: fix t → spatial Wigner (x,k); fix x → temporal Wigner (t,ν). A "Marginals" strip shows M1, M2 and P recovered numerically with their errors and a CONSISTENT badge. Field: 1+1-D packets from Spectra sources A/B/C (pulse length, carrier, chirp, medium); two sources show the negative interference cross term midway; a single Gaussian stays positive (Hudson).
- **Scope** adds time–frequency modes for any stream: Spectrogram · Wigner–Ville · Pseudo-Wigner (with the |x(t)|² and |X(ν)|² marginals drawn on the edges). Whistle chirps, BLE hops, FID, mains hum.
- **Radio → Fourier** adds a Time–frequency view (Wigner–Ville vs spectrogram) of the transmitted signal; new system preset **FMCW radar chirp** (77 GHz automotive and a 24 GHz option) whose Wigner is a straight line.
- **Radio → Antenna** adds **Aperture phase space**: the spatial Wigner W(x,k_x) of the aperture current; its k marginal is the far-field pattern (k_x = k sin θ); a distance knob shears it (Fresnel) to show near field → far field; phased-array steering shifts it in k_x.
- **Spin**: FID in a field gradient is a chirp → Wigner view.
- **Patch** nodes: Wigner (stream → time–frequency image), Marginal (image → |x(t)|² or |X(ν)|²).

## 4. Spin tab (from Gyre)
Species picker: **Gyroscope · Proton · Electron** (+ "Compare" split view). One Metal holo scene: the spinning body (gyroscope rotor wireframe/holo-metal-lite, or a spin arrow on a Bloch sphere), the field vector B (live magnetometer direction & magnitude, or a knob), precession cone and trail.
- **Gyroscope**: heavy symmetric top ported from Gyre `GyroSim` (RK4, nutation substeps, ball pivot), driven by live device motion (gravity direction, rotation) — knobs Motor, Inertia, Gravity (detents Zero-g/Moon/Mars/Earth/Jupiter), Magnet (−1…1 with "Real NdFeB" 0.138 and "Electron-like" −1 detents), Friction, Air, Time (κ). Readouts Ω_p, nutation f, spin, |L|. Tip trajectory as an IQ signal (Patch source).
- **Proton / Electron**: Bloch equations with B₀ = live |B| (Earth field) or a knob up to 9.4 T (log, detents Earth 50 µT, fridge magnet 5 mT, MRI 1.5/3 T, NMR 9.4 T); γ from CODATA; RF field B₁ (CW or pulses π/2, π), detuning Δf, T₁, T₂; rotating-frame toggle (HETERODYNED). FID trace and its spectrum. **Hear it**: true-pitch Earth-field proton precession (~2 kHz at 50 µT) through HumSynth (FID ring-down envelope), electron at 1.4 MHz shown heterodyned only. Readouts f_L, ω, Rabi Ω = γB₁, T₂*, g−2 note for electron (cyclotron 1.39962 vs spin 1.40125 MHz in 50 µT).
- Links: "Show on spectrum" (Larmor λ marker), "Open in Lab" (NMR mode), "Add to Patch".

## 5. Patch tab (node graph)
Canvas (pan/zoom) of glass node cards; ports coloured by type; cables glow (hue by EM frequency for EM/IQ carriers, phosphor/amber for analogy and control); a mini live preview inside each node (sparkline, spectrum, constellation, value). Add-node palette sheet grouped by category; long-press a knob anywhere in the app → "Modulate from…" (Drives matrix, `gyre-integration.md` §7).

Node catalog (v1):
- **Sources**: Spectra source (em), Oscillator (sine/square/saw, f), Noise, Text/bits, Microphone (audio, LIVE/ANALOGY), Magnetometer (control + audio-rate-resampled, LIVE), Motion/attitude (attitude, LIVE), Barometer (control), Bluetooth RSSI (control per device, LIVE), Light (control), Gyroscope tip (iq, MODEL·LIVE), Spin FID (audio/iq, MODEL·LIVE|B|).
- **Process**: Modulator (AM/FM/PM/ASK/FSK/BPSK/QPSK/QAM-M/OFDM), Demodulator, Mixer, Filter (LP/HP/BP), Gain, Envelope follower (Gyre conditioner), Antenna (TX/RX, style; attitude input), Channel (distance, environment, walls, multipath, Doppler, AWGN), Medium (Spectra matter: transmission at λ), FFT.
- **Sinks**: Scope (time), Spectrum/waterfall, Constellation, Speaker (HumSynth), Haptics (Feel), Spectrum ruler (sends λ/f to the Spectrum tab = the loop), Knob target (modulation matrix).
Presets: "Voice over AM", "Voice over FM", "Wi-Fi 6 OFDM through two walls", "Live BLE link vs model", "Mains hum on the magnetometer", "Earth-field NMR you can hear", "Gyroscope steers a phased array", "Light meter → Spectrum".
Evaluation runs only while the Patch tab (or a node-dependent view) is visible; audio-rate graphs pull 1024-sample blocks for the synth.
