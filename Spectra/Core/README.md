# Core

Owner: **core-port**. Swift port of spectra-lab `src/core` + `src/data` + `src/ui/fieldview.js`
(see `Docs/research/port-plan.md`), parity-tested against `SpectraTests/Fixtures/vectors.json`
(11,746 cases). Public API: `Docs/API-core.md`. Gate: `Tools/check-core.sh`.

Pure Swift (Foundation + simd only), `nonisolated` value types and caseless-enum namespaces, so it
compiles in the app (Swift 6, default MainActor isolation) and in the plain macOS harness.

| File | Port of |
|---|---|
| `SI.swift` | `constants.js` |
| `SpectrumCore.swift` | `spectrum.js` (conversions, bands, colour, detents, comparisons, `describe`) + the native long-wave ruler (`rulerLogMax` 8) |
| `JSFormat.swift` | `spectrum.js` formatters, JS-exact `toFixed`/`toPrecision`/`String(x)`, `JSMath` |
| `WaveCore.swift` | `wave.js` (`WaveSource`, `Wave`) |
| `MatterComplex.swift`, `Matter.swift` | `matter.js` |
| `Specimens.swift` | `specimens.js` |
| `LabSamples.swift` | `samples.js` |
| `SpectraState.swift`, `SpectraPresets.swift` | `state.js`, `presets.js` |
| `Data/XCOMTables.swift`, `Data/SegelsteinWater.swift` | GENERATED by `Tools/gen-tables.mjs` from `src/data/*.js` — do not edit |
| `Display/FieldView.swift` | `ui/fieldview.js` |
| `Display/SpectrumDisplay.swift` | display mappings from `ui/app.js`, `ui/feedback.js`, `instruments/*.js` |

File names avoid generic basenames (`Spectrum.swift` already exists in `RF/DSP/`; Swift forbids two
files with one name in a module). `Tools/check-core.sh` step 0 guards this.
